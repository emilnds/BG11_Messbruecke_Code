Setup & Upload:

- Open Visual Studio Code.

- Make sure the PlatformIO IDE extension is installed.

- Open the project's main.cpp file.

- In the PlatformIO sidebar on the left (alien icon), click Open Project (folder icon).

- Select the project's root folder (the folder containing platformio.ini).

- Connect your ESP32 via USB.

- Click Upload (arrow icon in the bottom status bar) to compile and upload the code to your ESP32.
